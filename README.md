## ✅ 校验

- 信经与信条引文全部从 ccifellowship.org 抓取的数据中按编号取出（构建时 `assert` 节录是原文子串）。
- `build/verify.py`：把页面上每段 CCI 引文（93 块 / 122 段）与 **ccifellowship.org 现场页面** 及本地抓取 JSON 逐字比对，全部通过；三大信经背诵版全文 3/3 与 CCI 页面一致；威斯敏斯特引文 9/9 与 RTF-USA 数据一致；正文 371 处“引号”片段对照和合本/CCI/威斯敏斯特，≥7 字的未匹配 0 处。
- `tools/qa.py`：Playwright 在 375 / 768 / 1440 宽度检查 11 页的横向溢出、元素越界、文字裁切、页头重叠与 JS 错误：33/33 通过。

## 🛠️ 构建

```bash
python3 build/build.py      # 生成 docs/（需要 build/cache 中的和合本经文缓存，或可联网）
python3 build/verify.py     # 引文校验（会联网抓取 CCI 页面）
python3 build/build.py      # 把校验结果写入来源页
python3 tools/qa.py         # 需要 playwright + chromium
```

构建依赖本机数据：CCI 抓取 JSON（`/workspace/cci`）、Natural Earth（`/workspace/ne`）、威斯敏斯特 RTF-USA 数据；生成结果已提交在 `docs/`。

静态站点位于 `docs/`（无第三方 CDN、无外部字体、离线可用）。
