## ✨ v3.0.0 更新说明（相对 v2.0.0）

1. **目录大改（本版首要）**：正文标题按真实层级重组为 h2 / h3 / h4（例如各书卷页：书卷 → 背景 / 结构 / 神学 / 重点难点 / 应用 → 历史背景、文化区域、结构大纲、四个视角、重点、难点、记忆钩）。目录为真正的三级树：一级「一、二、…」，二级 `1.1`，三级 `1.1.1`。每一级可单独折叠，并提供「全部展开 / 全部折叠」。目录打开后可用鼠标或触控拖动边缘横向拉宽拉窄（有最小/最大宽度，宽度写入 `localStorage`）；长标题换行显示，不再被截断。目录仍可隐藏。窄屏变为抽屉，同样可在屏幕范围内调整宽度。顶部另有「全站」一级目录（跨页），其下是「本页」二、三级。滚动高亮当前章节，并自动展开该分支。
2. **顺滑度**：默认改为原生滚动（不再加载 Lenis；在同样脚本化滚动测试里，v2 的 Lenis 在重页上出现过 280–300 ms 的长帧）。滚动时暂停装饰性云层动画；去掉目录上的 blur；阴影减轻；被动滚动监听；IntersectionObserver + rAF 节流的滚动高亮；相邻页 `prefetch`；保留视图过渡。记忆页的题库与填空进入视口后再水合。
3. **结构与可视化**：地图馆按「行省 / 行程航海 / 收信地」分组；时间线页补上「罗马世界怎样托住福音」流程图；教义主题下分为「经文要义 / 信条对照」。配色略加暖、饱和，仍保持夜/日双主题。
4. **沿用 v2**：多源 Leaflet 底图 + 自动回退 + Natural Earth 离线矢量 + 成对概念图；六色笔记标记；三大信经背诵与对比；信条引文仍全部逐字取自 ccifellowship.org。

## 🛠️ 构建

```bash
python3 build/build.py      # 生成 docs/
python3 build/verify.py     # 引文校验（会联网抓取 CCI）
python3 build/build.py      # 把校验结果写入来源页
python3 tools/qa.py         # Playwright
```

静态站点在 `docs/`。Leaflet 与 Natural Earth GeoJSON 均本地打包。v3 不再加载 Lenis。
